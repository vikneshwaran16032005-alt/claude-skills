# Frameworks Quick-Reference Table

One-line index of every named framework in the direct-response canon. Source + purpose + when to reach for it. Scan this table when the user gives a copywriting task; match to the situation before loading deeper detail files.

| Framework | Source | Purpose | When to use |
|---|---|---|---|
| **RIOA** (Reader/Idea/Offer/Action) | Copy That | Rule-of-One checklist | Before ANY copy — define these 4 before writing a word |
| **AIDA** (Attention/Interest/Desire/Action) | Classic; taught by Halbert | Letter/ad structure | Default scaffold for any sales piece |
| **5 Stages of Awareness** | Schwartz | Gauge reader's prior knowledge of your product/solution | Start of every project — drives lead-type choice |
| **5 Stages of Market Sophistication** | Schwartz | Gauge how many competing claims the market has seen | Determines whether to use claim / bigger-claim / new-mechanism / identification |
| **One Belief + 10 Questions** | Albuquerque (16-Word Sales Letter) | VSL / long-form sales letter blueprint | Writing long-form sales pages at scale |
| **5-Part Sales Letter** (envelope/headline/lead/argument/close) | Masterson | Direct-mail architecture | Designing a DM package end-to-end |
| **6 Lead Types** (Offer/Promise/Problem-Solution/Secret/Proclamation/Story) | Masterson & Forde (Great Leads) | Match lead to awareness | Choosing HOW to open — direct for high awareness, story for low |
| **7 Techniques of Breakthrough Copy** (Intensification/Identification/Gradualization/Redefinition/Mechanization/Concentration/Camouflage) | Schwartz | Body-copy tools for sophisticated markets | When headline is set and body needs depth/credibility |
| **A-pile / B-pile** | Halbert | Envelope/first-impression design rule | Every direct-mail envelope, every email subject line + sender line |
| **HALT** (Hungry/Angry/Lonely/Tired) | Halbert | Self-check before decisions | Personal operating rule — not a copy framework per se |
| **Rule of One (5 elements)** (idea/emotion/story/benefit/response) | Masterson & Forde | Keep lead unified | Any lead you're writing |
| **Starving Crowd** | Halbert | Market-first thinking | Before choosing a product or niche |
| **RFU** (Recency/Frequency/Unit-of-sale) | Halbert | List quality lens | Evaluating mailing lists or audience segments |
| **3 Dimensions of Body Copy** (Desires/Identifications/Beliefs) | Schwartz | What body copy must alter in the reader | Planning body of long-form |
| **4 Categories of Proof** (Construction/Performance/Testimony/Test) | Schwab | Proof inventory | Collecting evidence for claims |
| **8 Milestones to Sale** | Schwab | Gauge how far copy must take the reader | Deciding length and intensity |
| **22 Interest-Holding Tactics** | Schwab | Readability toolkit | Editing body copy for flow |
| **38 Headline Verbalizations** | Schwartz | Headline idea generator | When stuck on a headline; see `lead-types.md` |
| **Dimensionalization** | Copy That | Make benefits visceral | Any generic benefit needs it |
| **Message Matching** | Copy That | Fulfill preceding-touchpoint promise | Sequences, funnels, ads-to-landing |
| **Customization** | Halbert | Personalize copy to segment | Writing to lists with known attributes |
| **Reason Why / Excuse for Deal** | Halbert, Collier | Make a proposition believable | Any discount/special-offer copy |
| **Nugget Notes** | Halbert | Research/ideation process | Starting a new project |
| **Copy-by-hand practice** | Halbert | Internalize good copy | Ongoing training — not per-project |
| **DIC** (Disrupt/Intrigue/Click) | Copy That (lift-email convention) | Short-email structure for traffic-driving emails | Lift emails linking to a sales page (don't recap the sales argument) |
| **HBC** (Hook/Body/Close) | Copy That | Universal copy structure (1 line to 1000 pages) | Every piece of copy at every length |
| **OCPB** (Objection/Claim/Proof/Benefit) | Copy That / Sean McIntyre | Body-copy pattern for overcoming a single objection | Each major objection in body copy; use multi-Proof (O-C-P-P-P-B) for skeptics |
| **FAB-DB** (Features/Advantages/Benefits/Deeper Benefits) | Sean McIntyre (expands classic F&B) | 4-level descent from spec to deepest yearning | Use all 4 for hard-to-sell offers (info, coaching); fewer for commodities with nascent demand |
| **3 Levels of Editing** (Value/Function/Line) | Sean McIntyre | Editing hierarchy — do in this order | After first draft — Value FIRST, Line LAST |
| **Spit Drafting** | Alex Mater | Plot what each section will SAY before writing words | Before drafting any meaningful piece — beats blank-page paralysis |
| **Reverse Outlining** | Copy That | Templating winning copy by mapping section purpose | When studying swipes — build structural patterns, not word patterns |
| **Ford Method** (Family/Occupation/Recreation/Dreams) | Copy That networking | 4 categories of icebreaker topics | Live networking; in-person sales-call "real talk" warm-up |
| **226 Follow-up Rule** | Copy That networking | Touch cadence for warm leads after meeting them | Anyone met at a networking event — 2 weeks, 2 months, 6 months |
| **Pro Rata Range Pricing** | Alex Mater | Per-project rate from your monthly income range × % of hours | Setting price for any project; gives floor + negotiation ceiling |
| **25/50/25 Daily Rule** | Bob Bly (via Sean) | Time split for a copywriting workday | Daily — Learning / Writing & research / Outreach |
| **Daily 3-Step Practice** (Study/Write/Idea) | Joe Schriefer / Kyle Milligan | Per-day deliberate practice | Every single day to compound 1% improvement |
| **Doctor Not Waiter** | Alex Mater / Copy That | Mindset for sales calls and pitching | Always: diagnose & prescribe, don't offer a menu |
| **Meta Close** | Alex Mater | Disarms hard-sell expectation, surfaces real objection | Sales call when prospect hesitates after hearing price |
| **Circle of Cred** | Sean McIntyre | Mental model — what you put on the table to demonstrate value | Any prospecting — in networking it's personality, online it's portfolio |
| **5 Subconscious Questions** (Relevance/Novelty/Benefits/Mechanism/Trust) | Copy That | Checklist of objections every reader has | Quick sanity-check on any draft before shipping |
| **10-Step Show-and-Tell Sales Call** | Alex Mater | Full sales-call structure | Any client-acquisition call |
| **PAS** (Problem/Agitate/Solution) | Classic | Short-form persuasion structure | Short ads — use as a starting template only; don't marry it |
| **4 Ps** (Promise/Picture/Proof/Push) | Henry Hoke | Short-form alternative to PAS | Short pieces where PAS feels wrong |

## How to read this file
When the user gives a task, scan this table for the applicable framework(s), then open the corresponding detail file. Don't guess which framework applies — match it to the situation.
